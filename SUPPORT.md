# FaceLink support

FaceLink is alpha software maintained by volunteers.

- Use [GitHub Discussions](https://github.com/xuebazhou-blip/FaceLink/discussions) for setup
  questions, workflow ideas and general help.
- Use the bug form for reproducible FaceLink defects.
- Use the feature form for scoped product proposals.
- Use [private vulnerability reporting](https://github.com/xuebazhou-blip/FaceLink/security/advisories/new)
  for security issues. Never post API keys, bearer tokens or private `.blend` assets.

Please include the FaceLink version, Blender version, operating system and the smallest safe
reproduction you can provide. Windows is the only fully verified platform in v0.3.6.
